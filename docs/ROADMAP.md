# 迭代路线

## 迭代一 · 机制闭环（本次交付）

目标：证明「双资源 + 六部族 + 阶梯价位」在 Godot 上跑得通，且手机端操作可用。

- [x] 塔防内核接入（MIT 上游，未改动）
- [x] 功勋系统：击杀归属、档位解锁、人口、三个主动技能
- [x] 32 个防御单位 / 6 部族 / 7 档阶梯价位
- [x] 15 波关卡、5 种敌人（含 BOSS）
- [x] 竖屏 HUD（自绘 + 手动命中测试）
- [x] 建造预览：网格吸附 / 射程圈 / 落子前的原因提示
- [x] headless 自测（覆盖本项目独有机制）
- [ ] **运行时验证 —— 待你在装了 Godot 的机器上跑一次**

**出口标准**：能在手机上完整打完 15 波，且「3 秒内完成一次精准造塔」。

## 迭代二 · 从「机制闭环」到「能玩」（本次交付）

原来的迭代二列的是「机制补齐」。改掉的原因是：**补齐机制不等于好玩**。
一局 12 分钟里玩家只在开局造三个塔，剩下全在看 —— 问题不是机制不够，是没有决策和操作。
完整诊断见 `docs/FUN.md` 第三节「五个具体病症」。

这一轮按 `docs/FUN.md` 的三根支柱做：决策 / 操作 / 成长。

### 决策（把「等」变成「要不要现在开」）

- [x] **波次情报**：常驻显示下一波构成（类型 + 数量）与一句克制建议。
      `TDWaveSpawner.wave_preview()` 早就写好了，之前从没被调用过。
- [x] **手动开波 + 提前开波奖励**：12 秒准备倒计时，提前开波按剩余秒数折金币（上限 24），
      归零自动开波不拿奖励。这是塔防品类最便宜的「把玩家拽回驾驶座」改动。

### 操作（RPG 的那双手）

- [x] **英雄单位**：可拖动、自动索敌、随击杀升级。
      **击杀给金币但不给功勋** —— 功勋只认 `TDTower.kills`，这条规则不靠文档提醒，靠代码路径保证。
- [x] **装备掉落**：敌人死亡 14% 掉落，英雄走过去自动拾取。
      三槽（剑 / 符 / 靴）分别影响攻击力、攻速、移速与射程。

### 成长（一局之内有变化）

- [x] **三合一合成**：重复装备攒 3 件自动升一级，不需要额外的合成面板。
- [ ] 装备词条随机化（现在只有固定的三档数值，还不足以让两局不一样）

### 克制（六个部族终于不只是六套数值）

- [x] **毒**：游侠系命中附带 DOT，**无视护甲**。实现方式是给 `take_damage` 传 `dmg + armor`，
      正好被内核的 `max(1, amount - armor)` 抵消。毒击杀的功勋手动补记给施毒的那座塔。
- [x] **眩晕**：狂战 / 剑咏命中清零目标速度，BOSS 的眩晕时长打 0.35 折。
- [x] **分裂**：重装死亡裂成两只斥候，惩罚「只堆单体输出、清场慢」的构筑。
- [ ] 弹射（chain）：命中后向最近目标跳一次
- [ ] 召唤物：能造成伤害但不进 `tower.kills`（规则天然合规，直接复用）

### 还没做（下一轮）

- [ ] **BOSS 阶段转换**：血量 70% / 40% 切换技能。现在第 15 波只是「血更厚的大怪」
- [ ] **结算归因页**：告诉玩家「你死于第 N 波的 X 类型」。没有归因就没有学习
- [ ] **难度阶梯**：一个难度都还没调平衡
- [ ] 第二张地图（双入口分叉）

**出口标准（MVP）**：一局 12–15 分钟，玩家手不离屏，并且能说出
「这局我打输了是因为第 10 波我没补对空」这种话。四条可验证标准写在 `docs/FUN.md` 第四节。

## 迭代三 · 留存结构（约 6–8 周）

这一轮才碰商业化。在机制没打透之前做养成，等于给一个不好玩的游戏加长留存曲线，是把问题往后推。

- [ ] 局外养成：六条职业线，各自的图腾收集（原版的「集齐一套图腾给全局加成」）
- [ ] 存档与云同步（本地存档先做，云同步随账号系统）
- [ ] 难度阶梯：简单 / 普通 / 困难 / 天才，用 `hp_scale_per_wave` + 出生金币区分
- [ ] 每日目标 + 周常挑战（用现有波次数据组合，不新增内容）
- [ ] 异步 PvP：用别人的防守阵容当关卡，排行榜
- [ ] 新手引导：前 3 波强制教学，重点教「双资源」这一件事

**出口标准**：次日留存能上 30%（塔防品类的中位线），7 日留存 8% 以上。

## 迭代四 · 商业化与合规（视数据决定）

- [ ] 广告位：复活 / 加速 / 双倍奖励（塔防的广告容忍度高于抽卡）
- [ ] 内购：部族解锁（内容型）+ 皮肤（外观型），**不做数值售卖**
- [ ] 世界观重做：原版的「人族 / 雅典娜 / 魑魅魍魉」属于暴雪 IP 与原作者，必须全部替换
- [ ] 隐私合规：安卓权限、SDK 清单、未成年人保护
- [ ] 性能目标：中低端机（骁龙 660 级）稳定 60fps，包体 < 80MB

**红线**：世界观与美术在商业化前必须 100% 重做。机制可以借鉴（不受版权保护），
名称、角色、剧情、美术一个都不能留。

## 已知技术债

| 项 | 位置 | 说明 |
|---|---|---|
| `content.json` 由脚本生成 | `tools/gen_content.py` | 想改数值必须改脚本再重新生成，直接改 JSON 会在下次生成时被覆盖 |
| HUD 全自绘 | `game/hud.gd` | 元素一多会难维护；超过 ~40 个可交互元素就该换回 Control 树 |
| 单位渲染在 main 里 | `game/main.gd::_draw_*` | 现在是几十个单位，性能没问题；上到 200+ 时要把单位改成独立 Node2D + 贴图 |
| 无对象池 | `td_core` 的 spawn/remove | 波次间隔短、同屏单位多时会触发 GC 抖动，迭代二再优化 |
| 无存档 | — | 迭代三 |
